# 交流互动台 v1.0 · 免费静态版

新能源汽车海外销售英语系统的独立练习模块。无需模型 API、付费服务器、数据库、账号或 npm 依赖。界面沿用深蓝侧栏、浅蓝背景和场景卡片。

## 已实现

- 四场景、32 道本地教学题、32 段按客户国家选用的合成音色 MP3，以及 32 段标准英语 WAV 备用音频。
- 每场景 8 道不同录音题：4 名泰国客户与 4 名其他东南亚客户。每轮第一题泰国、第二题非泰国；同一浏览器中抽过的题不会再次抽取。每场景最多练习 4 轮，题库用完后停止出题。客观项和追问主题随机排序。
- 客户录音只陈述自然的购车需求，不直接提示尚未说明的家庭人数、日常细节或竞品车型；学生根据听到的信息自行判断追问方向。
- 真实音频播放、暂停、重听、拖动进度、0.8 倍速、最后 5 秒倒计时（按当前播放速度折算实际剩余时间）。
- 已知信息 6 项多选、追问主题 6 项单选、英语输入、浏览器语音识别可用时增强。前两场景另有客户画像和教学模拟车型匹配判断。麦克风未授权或服务不通时，使用文字输入。
- 逐题模拟客户回复、规则参考评分；回复优先根据实际英语问题识别需求，不受所选追问主题限制。无法确定意图时引用问题内容进行澄清。提交后在原选项下显示对错、正确答案和证据；追问评价仅在场景成绩页显示。
- 两题平均总分与称号、草稿与未完成练习恢复。已移除本机练习记录页面及入口。
- 手机适配和嵌入模式、完成事件/回调，详见 INTEGRATION.md。

## 使用

解压后可直接打开 index.html。推荐用 HTTP/HTTPS：有 Node.js 的电脑运行 `node preview-server.cjs`，访问 http://127.0.0.1:8765 。没有 Node 也可以交给同事放到现有静态站点。

播放只依赖打包的 WAV 文件，不依赖 Windows 或网络语音生成服务。麦克风识别是可选增强，需浏览器支持及安全上下文（HTTPS/localhost），可能将音频交给浏览器厂商的在线识别服务。当前版本不上传题目作答或成绩到自建服务。

本机存储可能因隐私模式、空间限制、清理浏览器数据而失效。页面会在存储失败时提示，并仍可继续练习。不同设备或域名不共享记录。

## 评分边界

客观项：max(0, 50 × (正确勾选数 − 误选数) / 正确项数)。

追问项：主题合理性 10 + 精准度 20 + 表达结构 10 + 有效性 10。已知主题或次要主题会减少对应分值。检测实际问句/请求及所选主题的必要词组，支持常见同义表达，并检查有限常见语法错误与冒犯用语。

这不是生成式 AI、通用英语语法检查器或发音测评。客户回复使用本地意图规则与客户事实库，能覆盖常见问法，但不能保证理解所有自由表达；未识别时会针对实际输入请求澄清。规则未识别不代表表达错误，规则满分也不代表语言毫无错误。非正式考试成绩；完整销售回应、车型选择与谈判技巧不单独评分。题库和评分建议由授课教师审核后再用于课堂。

## 内容与音频维护

- scripts/build-content.cjs：编辑客户事实、选项证据、隐藏事实、主题规则和标准表达。
- `node scripts/build-content.cjs`：重新输出 data.js 和 audio-scripts.json。
- Windows 下运行 `./generate-audio.ps1`：使用本机 Microsoft Zira 英语声音重新生成 32 段 WAV。无需付费 API，学生无需执行此脚本。
- 地域音色是合成语音近似演示，不等于真实当地说话者的英语口音；各段需教师核听可懂度、发音与台词准确性。`audio/*.wav` 是标准英语备用音频。可按 `REGIONAL_AUDIO_GUIDE.md` 替换为获得许可的真人录音；改动台词须同步题库、翻译和证据。
- 四场景使用同一客户池但任务语音不同；客户与购车条件属于模拟材料，不应当作真实车型参数、报价或服务承诺。

## 开发与验证

- `node --test tests/core.test.cjs`：题库、随机抽题、计分与常见误判检查。
- `node --check app.js`：脚本语法检查。
- 浏览器检查与未验证项见 VALIDATION.md。
- `node scripts/package.cjs`：在 deliverables 下输出完整交付目录，包含源文件和静态运行文件，没有密钥。

## GitHub Pages

运行 `node scripts/build-pages.cjs` 可生成仅含页面运行文件和音频的 `dist` 目录。仓库内的 `.github/workflows/pages.yml` 在推送到 `main` 后运行测试、构建并发布 `dist`。相对资源路径与 hash 导航支持仓库子路径，保留 `.nojekyll`。

发布前应在学校网络和学生手机上实际试用。当前未执行 GitHub 发布；本地地址不能作为学生公网链接。公开仓库中的题库与答案可被查看，不适用于防作弊考试。
